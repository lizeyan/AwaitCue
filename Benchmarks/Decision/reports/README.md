# Public benchmark reports

This directory contains aggregate-only reports derived from completed, blind-reviewed local runs.

Never add raw screenshots, activity summaries, sample JSON, human-review manifests, private
comparison/replay reports, endpoint configuration, or API credentials here. Generate a report with
the `public-report` command documented in the parent benchmark README, inspect its strict allowlist,
and keep every source artifact under the Git-ignored `.local/` directory.
